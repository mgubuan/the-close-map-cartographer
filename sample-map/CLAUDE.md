Rules:

- Source territory wins when a card disagrees.
- For a change question, load the change-impact catalog, one card, and its cited source.
- Do not load the whole `objects/` folder.
- Open a second card only when the first card explicitly requires it.
- `live` participates now; `leftover` is retained but not primary; `ghost` has a name but no wiring.
- Stop at first-order impact; this is a system map, not a tour of every close step.
- Stop and report a catalog gap when no door matches.
