# Map Contract

## Territory

This map describes the privacy-safe `CRHS-042 / 2026-07` bookkeeping close in `../demo-territory/client-workspace/`: required client records, transaction completion, reconciliations, key balance checks, supported month-end entries, bookkeeping review, and report delivery. It excludes tax advice, accounting-policy decisions, credentials, and client values.

## Universes

- `live`: currently written, read, or used for an operational decision.
- `leftover`: intentionally retained but not the primary path.
- `ghost`: named or filed but not wired.

`UNKNOWN` is a query result, not a universe.

## Name collisions

- **Complete** means the named control has evidence, not that a checkbox is checked.
- **Reconciled** means tied to independent support, not that a feed balance matches.
- **Reviewed** is not delivered.
- **Entry** means a posted, supported record, not a draft or email instruction.
- **Old Close Checklist** names a ghost; the live starting control is `Client Records Ready`.

## Reading contract

1. Start in `CLAUDE.md`.
2. Route through `effects/CONTEXT.md` for a change question.
3. Open one primary object card.
4. Follow one `See` citation into source.
5. Open another card only if the first card requires it.
6. Stop at first-order impact.

## Authority

Subject source wins over map. Current registers and explicit rules win over filenames, folder names, and retained notes.
