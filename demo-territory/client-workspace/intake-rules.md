# Intake Rules

Source documents may arrive through the controlled intake email or the client portal. Each accepted file receives a workspace ID, period, document type, and source reference before it can support work.

If expected evidence is missing, unreadable, duplicated, or cannot be matched to its workspace and period, create or update a row in `exception-register.csv`.

`archive/Missing Documents.xlsx.note.md` describes a retained historical workbook. It is not the live exception destination.
