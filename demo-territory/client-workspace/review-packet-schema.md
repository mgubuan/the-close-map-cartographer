# Review Packet Schema

A review packet identifies exactly one workspace and period. It contains:

- packet ID;
- assigned preparer;
- assigned reviewer;
- included work-record IDs;
- source-document references;
- reconciliation evidence references;
- disclosed open exceptions;
- submitted timestamp.

A folder named `Approved` is not approval evidence. Approval exists only as an explicit row in `approval-register.csv` naming the packet, reviewer, status, and timestamp.
