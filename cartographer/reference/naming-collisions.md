# Naming Collisions

| Word | Possible meanings |
|---|---|
| Client | Legal entity, engagement, contact, or workspace |
| Statement | Bank statement, vendor statement, or financial statement |
| Reviewed | Opened, checked, approved, or client-accepted |
| Complete | Received, posted, reconciled, review-ready, or approved |
| Exception | Missing evidence, accounting discrepancy, or reviewer question |
| Close | Period, checklist, workflow state, or completed control |
| Owner | Client owner, task assignee, relationship manager, or file owner |
| Account | Bank account, ledger account, portal account, or customer account |

When a collision is present, the card must state the local meaning and cite the source that establishes it.
