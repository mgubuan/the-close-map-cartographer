# Walk Order

## When mapping a territory

0. **Inventory:** list the tree and classify areas as catalog, contract, factory, product, or dead. Do not write cards.
1. **Catalog:** write the entry files, map contract, schema, templates, and noun index with stubs.
2. **Nouns:** verify object cards from source. Record universe, revision, date, and citations.
3. **Verbs:** write only movements proven to run or be followed.
4. **Effects:** route a proposed change to the minimum cards required.
5. **Re-verify:** inspect every load-bearing `Hits` and `Does not hit` claim again.

Stop after each slice for human review.

## When answering a change question

1. Open `map/CLAUDE.md`.
2. Resolve any colliding name from `map/CONTEXT.md`.
3. Open `map/effects/CONTEXT.md` and choose the matching change door.
4. Open one primary card.
5. Follow a `See` citation into the subject source.
6. Open another card only when the primary card’s gate requires it.
7. Stop when the first-order `Hits` and `Does not hit` boundary is established.

Never load the whole `objects/` shelf.
